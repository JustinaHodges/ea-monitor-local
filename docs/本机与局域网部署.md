# 本机 / 局域网部署

本仓库专门给「没有云服务器、只在自己电脑跑」用。

## Windows

1. 安装 [Node.js 20 LTS](https://nodejs.org/)
2. 双击 `start-local.bat`（仅本机）或 `start-lan.bat`（局域网）
3. 浏览器打开窗口里提示的地址，用 `server/.env` 里的 `ADMIN_TOKEN` 登录

若 `npm install` 报编译错误：安装 Visual Studio「使用 C++ 的桌面开发」后重试。

防火墙：局域网模式需放行 TCP **8787**。

## macOS / Linux

```bash
chmod +x start-lan.sh
./start-lan.sh
```

## 和云端仓库的区别

| | 本仓库（本机版） | [ea-monitor](https://github.com/JustinaHodges/ea-monitor) |
|--|--|--|
| 目标 | 个人电脑 / 局域网 | VPS + 域名 7×24 |
| 启动 | 双击 bat / shell | 宝塔 / systemd / Nginx |
| 关机 | 站点停止 | 服务器可一直在线 |

功能相同，只是部署方式不同。
